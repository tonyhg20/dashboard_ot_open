# OS Open Dashboard

Command-center dashboard for **field-service work orders (OT)** — live map of open orders, per-hub metrics, noise analysis, and automated executive reports.

> **Demo project.** All data in this repository is **fictional** — generated by a synthetic seed. No real operational data, credentials, or private information is included.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | FastAPI (Python) |
| Database | PostgreSQL 16 |
| Frontend | Next.js (React) |
| Reports | Jinja2 → Monarch dark-theme PNG (executive report) |
| Infra | Docker Compose |

## Architecture

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────────┐
│  Frontend    │ ──▶ │  FastAPI backend │ ──▶ │  PostgreSQL      │
│  Next.js     │     │  /api/*          │     │  abiertas        │
│  :3001       │ ◀── │  :8000           │     │  completas       │
└──────────────┘     └────────┬─────────┘     └──────────────────┘
                              │
                              └──▶ Executive report v2 (Jinja2 → PNG)
```

- **Map view**: live markers per hub with order totals (IN / TC / RA / Rx)
- **Metrics**: per-hub KPIs for the selected day
- **Noise map**: order density by postal code
- **Executive report**: dark Monarch-style dashboard rendered from the latest 7 days, with KPI cards and sparklines

## Quickstart

### 1. Configure environment

```bash
cp .env.example .env
```

The defaults work out of the box for the Docker compose stack (`DB_HOST=db`, `DB_PASS=changeme`).

### 2. Start the stack (builds backend + frontend, starts Postgres)

```bash
docker compose up -d --build
```

The `db` service starts first, the `seed` service creates the tables and inserts ~120 days of fictional orders, and only then the backend starts.

### 3. Seed the database manually (optional)

If you ever want to regenerate the demo data:

```bash
docker compose run --rm seed python scripts/seed_demo.py
```

### 4. Open the dashboard

- **Dashboard:** http://localhost:3001
- **API docs:** http://localhost:8000/docs
- **Executive report (open in browser, capture screen):** http://localhost:8000/api/reportes/executive/generate-v2

The dashboard uses 5 fictional hubs — `ZAP`, `VIL`, `TUX`, `SOT`, `GRA` — with invented coordinates and order data.
